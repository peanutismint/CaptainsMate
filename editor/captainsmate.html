Quick start

  1. Click the folder button Load config to load your config (or start with the default).
  2. Click a key in the grid. Its settings appear on the right.
  3. Click Connect pedal (Chrome or Edge). From then on every edit is sent to the pedal after half a second.

The screen

Left: pages and global settings. Middle: the 10 keys, expression and encoder, and a preview of the pedal screen. Right: the inspector for the selected key. Click a key to simulate a tap; Shift-click simulates a long press. The preview shows the pop-up the pedal would show.

Keys & states

Each key has a label and color. Action is either keytimes (send MIDI) or a page key. A keytimes key has short (tap) and long (hold) states. With several short states, each tap moves to the next one, which is how a key toggles on/off or steps through choices. Each state has its own label and LED color, and lists of messages sent on down (press) and up (release).

Messages

Use + message inside a state. Types:

  • cc: control change, number 0-127 and value 0-127.
  • pc: program change to a preset number. pc_inc / pc_dec step to the next or previous preset.
  • cc_inc / cc_dec: step a counter between its min and max (set on the key), optionally wrapping.
  • note: note number and velocity.

The ch box on a message sets its MIDI channel (1-16). Blank uses the global channel.

Pages

A page is a full set of 10 keys. Add pages with + page. Set a key's Action to page_inc or page_dec to move between pages from the pedal.

Expression & encoder

Each expression input sends a CC that follows the pedal between min and max; ch sets its channel. The encoder (wheel) can send a CC when turned, or move between pages (set does to page; reverse swaps direction). Leave Expression off until a pedal is plugged in. Untick on to disable an input, which is best for unplugged pedals.

Global & settings

  • MIDI ch: default channel for everything.
  • Hold ms: how long counts as a long press.
  • SPI MHz: screen speed; needs a restart.
  • Settings (gear): Dev mode shows the pedal as a USB drive at every boot, and Restart pedal. Battery: charging for NiMH AAs (off by default, never with alkaline), an on-screen battery display as voltage, percent or an icon, and a Probe button to find the right sense pin.
  • Sun/moon icon cycles Auto, Light and Dark. Tooltips turns hover hints on or off.

Live update

Click Connect pedal, pick the pedal's port, and keep Live update ticked. The green dot means connected. Send pushes your config to the pedal now; Receive loads what the pedal has. Close other serial programs first, since only one can use the port.

Saving & backups

Import pages merges pages from another config file into this one: tick the pages you want and where they go (you can also drop a file onto the editor). Export in the page bar saves just the current page as a small file you can import elsewhere. The size chip at the top shows how big the config is; above about 12 KB the pedal may run out of memory.

Save config saves a file on your computer; do this before big changes. With dev mode off, live edits are also saved on the pedal. With the USB drive mounted the pedal cannot save, so changes last until power-off. Holding switch 1 while plugging in always shows the drive.

Troubleshooting

  • Connect fails: close other serial consoles, and check the pedal runs code.py v0.3 or newer.
  • Device ignores the pedal: check MIDI channel match, and USB versus 5-pin DIN cabling.
  • Preset off by one: MIDI counts from 0, many devices from 1.
  • Counter out of sync: the pedal can't read the device's value; reset the key or re-send.
  • Stray expression values: disable unplugged inputs.

MIDI basics (click outside to close)

What is MIDI?

MIDI doesn't carry sound. It carries short commands, like a remote control: "switch to preset 5", "turn knob 11 to 64". Your pedal sends these to your amp, modeler, headphones, synth, or any other MIDI gear.

Channels (1-16)

Think of channels as radio stations on one cable. A device only listens to messages on its own channel. If a device ignores your pedal, a channel mismatch is the number one suspect. Set it in Global → MIDI ch.

Control Change (CC)

A knob or switch. Each has a CC number (0-127) and a value (0-127). "CC 11 = 64" means set control #11 to 64. Switches are usually 0 = off, 127 = on (or 0, 1, 2... for multi-position choices like an effect type or amp model).

Program Change (PC)

Recalls a preset by number (0-127). Many devices show presets as 1-128 while MIDI counts from 0, so preset 1 is PC 0. This is the usual off-by-one.

SysEx

System Exclusive messages are longer, device-specific commands, written as hex bytes (for example F0 7E 7F 06 01 F7). Your device's MIDI implementation chart lists them. The pedal adds the F0 start and F7 end bytes if you leave them out.

Press (macro)

A press message makes this key tap, or long-press, other keys for you. Put several messages in one state to, for example, send a CC and press keys 3 and 4 (write 3, 4). Leave page blank for the current page. Each target key moves to its next state just as if you had pressed it.

Notes

A key pressed on a keyboard: note number 0-127 (60 = middle C) and velocity (how hard, 1-127). Rarely needed for effects; useful for triggering synths or samplers.

Press, release, short, long

Each key can send messages when pressed (down) and released (up). A long press (hold longer than "Hold ms") can do something different from a tap. Keys with several short states step through them on each tap.

Counters

Up/down keys (cc_inc / cc_dec) remember a value and step it within min and max. The pedal can't ask the other device what it's set to, so if you change a knob on the unit itself, the pedal's number drifts out of sync.

USB vs 5-pin DIN

The pedal sends everything to both. Hardware with 5-pin MIDI jacks uses the DIN cable; computers and USB gear use USB.
